# Agent Questions documentation

Agent Questions is an MCP server with a web UI. An agent calls the `ask_user` tool to ask you long or complex
questions (markdown context, code, many options); you answer in a form, and the answers return to the agent.

New here? Read the [README](https://github.com/Morbakos/agent-questions#readme) for the quick start, then pick your
path below.
